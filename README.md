# DialogueSystem-MVVM

Модульная система диалогов для Unity, реализованная с использованием архитектурного паттерна **MVVM (Model–View–ViewModel)**.  
Поддерживает ветвящиеся диалоги, выборы с разными типами последствий и анимированный UI.

Проект создан с упором на **чистую архитектуру**, масштабируемость и удобство поддержки.

---

## ✨ Возможности

- 🧠 Архитектура **MVVM**
- 🌳 Ветвящиеся диалоги на основе `DialogueNode`
- 🎯 Система выборов с разными типами:
  - Переход к следующему узлу
  - Выдача квеста
  - Выдача награды
- 📦 Хранение данных диалога через **ScriptableObject**
- 🎨 UI-анимации с использованием **DOTween**
- 🔔 Событийная модель взаимодействия между слоями

## 🧠 MVVM — роли слоёв

### Model
Отвечает за данные и состояние диалога:
- текущий узел
- текст реплик
- события начала и окончания диалога

---

### ViewModel
Связывает Model и View:
- не зависит от Unity API
- проксирует данные
- управляет логикой диалога через события

---

### View
Отвечает только за отображение:
- UI
- кнопки выбора
- анимации
- пользовательский ввод

---

## 📦 ScriptableObject

Диалоги хранятся в `Dialogue` (`ScriptableObject`), что позволяет:
- редактировать диалоги без изменения кода
- переиспользовать систему
- отделить данные от логики

---

## 🎯 Choice System

Каждый `DialogueNode` содержит список `Choice`.

Типы выборов:
- `DialogueNode` — переход к следующему узлу
- `Quest` — логика получения квеста
- `MoneyGive` — логика получения награды

Система легко расширяется под новые типы.

---

## 🎨 UI Animation Service

Анимации вынесены в отдельный сервис:

- масштабирование элементов
- появление и скрытие UI
- централизованное управление DOTween

Это снижает связность и соблюдает **SRP**.

---

## 🚀 Использование

1. Создай `Dialogue` через:

Create → CreateDialogue

2. Заполни `DialogueNode` и `Choice`
3. Назначь `Dialogue` в `DialogueView`
4. Запусти сцену — диалог стартует автоматически
