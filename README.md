# 💬 DialogueSystem-MVVM

![Unity](https://img.shields.io/badge/Unity-2021.3%2B-blue?logo=unity)
![C#](https://img.shields.io/badge/C%23-7.3-green?logo=csharp)
![License](https://img.shields.io/badge/License-MIT-orange)

Модульная система диалогов для Unity, построенная на базе архитектурного паттерна **MVVM (Model–View–ViewModel)**. Проект спроектирован с фокусом на **чистую архитектуру (Clean Architecture)**, масштабируемость и полное разделение логики и представления.

---

## ✨ Основные возможности

* **🧠 MVVM Workflow** — строгая изоляция данных от UI-логики.
* **🌳 Ветвление диалогов** — поддержка сложных деревьев диалогов через `DialogueNode`.
* **🎯 Гибкая система выборов** — разные типы исходов:
    * Переход к следующему узлу.
    * Триггер квестовых систем.
    * Выдача наград (валюта, предметы).
* **📦 Data-Driven подход** — хранение данных в `ScriptableObject` для удобного редактирования без программиста.
* **🎨 Плавный UI** — встроенный сервис анимаций на базе **DOTween**.
* **🔔 Event-Based** — взаимодействие слоев через события для минимизации зависимостей.

---

## 🧩 Архитектура проекта

Проект организован по классической схеме MVVM, что обеспечивает легкость тестирования и поддержки.

```text
DialogueSystem-MVVM
├── 📁 Model          # Данные и состояние диалога
│   ├── DialogueModel
│   ├── DialogueNode
│   └── Choice
├── 📁 ViewModel      # Прослойка (бизнес-логика, трансляция данных)
│   └── DialogueViewModel
├── 📁 View           # UI-компоненты и отображение
│   ├── DialogueView
│   └── ChoiceButton
├── 📁 Services       # Вспомогательные сервисы
│   └── UiAnimatorService
└── 📁 Data           # ScriptableObjects
    └── Dialogue

🧠 Роли слоев
Слой	Ответственность	Зависимости
Model	Хранение текущего узла, текста и событий состояния.	Нет
ViewModel	Управление логикой переходов, фильтрация данных для View.	Model
View	Отрисовка текста, инстанцирование кнопок, запуск анимаций.	ViewModel
📦 Система данных (ScriptableObject)

Диалоги хранятся в виде ассетов Dialogue. Это позволяет:

    Редактировать контент "на лету" без пересборки проекта.

    Переиспользовать одну и ту же систему для разных NPC.

    Полностью отделить работу сценариста от кода.

🎯 Choice System (Типы выборов)

Каждый узел диалога (DialogueNode) содержит список Choice. Благодаря полиморфизму, система легко расширяется:

    DialogueNode — просто ведет к следующей реплике.

    Quest — вызывает событие старта задания.

    MoneyGive — интегрируется с системой экономики.

🎨 UI Animation Service

Анимации вынесены в UiAnimatorService (соблюдение SRP — Single Responsibility Principle):

    Использование DOTween для эффектов появления/затухания.

    Масштабирование элементов интерфейса.

    Централизованная настройка длительности и типов кривых (Easing).

🚀 Быстрый старт

    Создайте диалог: Правой кнопкой в Project → Create → Dialogue.

    Настройте узлы: Заполните текст реплик и создайте варианты выбора (Choice).

    Привяжите данные: Перетащите созданный ассет в поле Dialogue компонента DialogueView на сцене.

    Запустите: Диалог инициализируется автоматически при старте или по событию.

🛠 Технологический стек

    Unity (Engine)

    C# (Logic)

    DOTween (Animations)

    TextMeshPro (UI Text)

    ScriptableObjects (Data Storage)

📈 Планы по развитию
```
